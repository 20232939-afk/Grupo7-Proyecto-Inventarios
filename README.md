# Simulador de escenarios de inventario – Grupo 7

Aplicación Streamlit del proyecto *Modelamiento Predictivo de Datos* (EC2 – Parte A).

- Archivo principal: `app/app_inventarios.py`
- Motor de simulación: `scripts/simulador_inventario.py`
- Insumos: pronóstico validado (`outputs/etapa3`) y supuestos de costo (`outputs/etapa4b`)

Ejecutar localmente:

```
pip install -r requirements.txt
streamlit run app/app_inventarios.py
```
